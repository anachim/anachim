### 🦀 Wavvon

A self-hosted, federated voice and text chat platform for communities. No central servers and no accounts: identity is an Ed25519 keypair owned by the user.

| Repo | What it is |
|---|---|
| [Wavvon-server](https://github.com/Wavvon/Wavvon-server) | Rust hub server: Axum, PostgreSQL, WebSocket, Opus-over-UDP voice relay, federation |
| [Wavvon-clients](https://github.com/Wavvon/Wavvon-clients) | Tauri 2 desktop client: React, TypeScript, voice, E2E-encrypted DMs |
| [Wavvon-sdk-dotnet](https://github.com/Wavvon/Wavvon-sdk-dotnet) | C#/.NET 8–10 SDK for bots and apps (also in [TypeScript](https://github.com/Wavvon/Wavvon-sdk-js), [Python](https://github.com/Wavvon/Wavvon-sdk-python), [Rust](https://github.com/Wavvon/Wavvon-sdk-rust)) |
| [Wavvon-docs](https://github.com/Wavvon/Wavvon-docs) | Architecture, wire format, API spec, roadmap |
